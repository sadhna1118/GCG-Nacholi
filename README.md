# Government College for Girls, Nacholi (Faridabad)

Official modern web portal for **Government College for Girls, Nacholi (Faridabad), Haryana**.
- **Affiliation:** Maharshi Dayanand University (MDU), Rohtak
- **Department:** Directorate of Higher Education, Government of Haryana
- **AISHE Code:** C-63189
- **Official Source:** [http://gcgnacholi.ac.in/](http://gcgnacholi.ac.in/)

## 🚀 Live Demo
- **GitHub Pages:** [https://sadhna1118.github.io/GCG-Nacholi/](https://sadhna1118.github.io/GCG-Nacholi/)

## ✨ Key Features
- **100% Official Scraped Assets:** Real college building banners, official logo, Principal's portrait, and 89 authentic event/sports photos.
- **Interactive Admission Fee Calculator:** Live fee & seat matrix calculations for B.A., B.Com, BCA, M.A. History, and M.Com.
- **Official Photo Gallery with Fullscreen Lightbox:** Dynamic category filters with high-resolution image viewer.
- **Online Grievance Redressal Portal:** Instant tracking ID generator & status lookup system.
- **Live Search & Circulars Board:** Searchable notices with PDF download links.
- **Accessibility Suite:** Font scaling (`A- / A / A+`), Dark Mode & High Contrast mode.
